# Sounds

`push1.wav` and `push2.wav` are original drum-machine stings made for this project, covered by the repo's MIT license. They take turns each time the hook fires.

Format: WAV, 44.1 kHz, 16-bit mono, about 2.2 seconds.

To use your own, don't edit this folder, since plugin updates replace it. Put WAV files in `~/.claude/push-it/sounds/` instead. See the README's [Customize](../README.md#customize) section.
